# Chapter 01_02 - 함수 오버로딩

C++은 함수 오버로딩을 허용하지만, C언어는 허용하지 않는다.
C++은 호출할 함수를 찾을 때, 함수의 이름과 매개변수의 선언을 동시에 활용한다.
하지만 반환형이 다를 경우엔 오버로딩이 이루어지지 않음
>> ex : void MyFunc(int n) / int MyFunc(int n) >> 이 경우 컴파일 오류



## FunctionOverloading.cpp

함수 이름이 같더라도 매개변수의 개수나 종류가 다르다면 오버로딩이 이루어진다.

## SwapFunction.cpp

함수 오버로딩과 포인터를 활용하여 swap 함수를 구현하였다.

함수를 이용하여 값에 영향을 줄 때 포인터를 사용하지 않으면 실제 값에는 영향이 없다.

이를 Call by Value라고 한다.
